# 四上班費收費通知單與套印系統

專為國小班級製作的班費收費通知單套印方案，支援全班 28 人一鍵生成、零跑版 A4 橫式一頁 6 張排版、收費名冊核對與學生姓名自動套印。

## 📂 專案檔案清單

### 1. 收費通知單列印檔
- **`班費收費通知_四上全班28人_橫式一頁6張.pdf`**（⭐ **直接列印首選**）
  - A4 橫式排版（3 欄 × 2 列），每頁 6 張，全班 28 人剛好 5 頁（含 2 張空白備用單）。
  - 零跑版、外框含淺灰裁切虛線，大小完美契合牛皮紙現金袋／中式信封。
- **`班費收費通知_四上全班28人_橫式一頁6張.docx`**
  - Word 橫式 6 張版（已關閉格線貼齊 `snapToGrid="0"`，防 Mac 次列溢出跨頁）。
- **`班費收費通知_四上全班28人_橫式一頁6張_含姓名版.docx`**
  - 含學生姓名套印完成版。
- **`班費收費通知_四上全班28人列印版.docx`**
  - A4 直式 4 合 1 版（備用方案，全班 7 頁）。
- **`班費收費通知_四上單張範本.docx`**
  - 單張卡片獨立範本。

### 2. 行政管理與自動化工具
- **`學生名冊與收費核對表_四上班費.xlsx`**
  - 內建 1～28 號座號、應繳金額、實繳金額、繳交狀態、家長簽章確認欄位與合計公式。
- **`自動套印學生姓名.py`**
  - 讀取 Excel 中的學生姓名，一鍵重新生成含姓名的 Word 檔：
    ```bash
    python3 自動套印學生姓名.py
    ```
